# Synthetic Global Collectible RPG Analytics — 한국어 요약

> 글로벌 캐릭터 수집형 턴제 모바일 PvE RPG의 출시 후 2년을 재현한 합성 데이터 기반 분석 프로젝트입니다.

이 프로젝트는 라이브서비스 운영 질문을 재현 가능한 데이터 분석 흐름으로 전환합니다. 분석 결과만 제시하는 데 그치지 않고, 테이블 Grain 정의, 데이터 품질 검증, 지표 정합성 확인, 분석 기준 설정, 시각화와 실행 제안까지 하나의 파이프라인으로 구성했습니다.

- **Data Analyst 관점 약 70%**
- **Analytics Engineering 관점 약 30%**
- 상세 분석·코드·문서는 영문으로 작성했습니다.
- 모든 데이터와 사건은 프로젝트를 위해 독립적으로 설계한 합성 자료입니다.

## 분석 목표

서비스를 개별 대시보드의 집합이 아니라 하나의 연결된 생애주기로 보고 다음 질문을 분석했습니다.

1. 대형 이벤트가 일시적인 트래픽만 만들었는가, 이후 활동까지 유지했는가?
2. 두 유명 IP 컬래버레이션이 유입 규모와 장기 리텐션에서 왜 다른 결과를 냈는가?
3. 이벤트로 유입된 이용자가 핵심 PvE 콘텐츠까지 도달했으며, 여정은 어디에서 끊겼는가?
4. 신규 PvE 구독 상품이 추가 매출을 만들었는가, 기존 상품의 소비를 이동시켰는가?
5. 장애 이후 이용자 복귀가 매출과 장기 리텐션 회복까지 의미했는가?
6. 전 지역에 공통으로 적용할 대응과 지역별로 구분할 대응은 무엇인가?

각 분석은 결과를 평가하기 전에 비교 기준선, 의미 있는 변화의 임계값, 지속성을 판단할 기간과 경고 조건을 먼저 정의했습니다. 인과관계를 입증할 수 없는 경우에는 이를 명시하고 기술적 복구, 행동 회복, 상업적 회복을 구분했습니다.

## 주요 분석 결과

### 1. 이벤트 확대와 서비스 의존도

2024년 라이브서비스 이벤트는 전체 일수의 17.5%를 차지하면서 연 매출의 33.3%를 만들었습니다. 2025년에는 이벤트 일수 비중이 31.0%, 매출 비중이 54.5%까지 증가했습니다.

첫 주년 이벤트의 DAU는 연말·연초 성수기 기준선보다 34.7% 높았고, 이벤트 이후에도 해당 기준선보다 49.9% 높은 수준을 유지했습니다. 다만 강한 기준선과 기간 중첩이 존재하므로 이를 순수한 주년 이벤트 효과로 단정하지 않고, 맥락적 지속성으로 해석했습니다.

[상세 분석](docs/findings/analysis_01_lifecycle.md)

### 2. 유입 규모와 장기 리텐션의 불일치

Fantasy 컬래버레이션은 기준 대비 79.2% 큰 신규 코호트를 유입시키면서 D30 리텐션도 2.74%p 개선했습니다. 반면 Astra 컬래버레이션은 코호트 규모가 50.1% 증가했지만 D30 리텐션은 2.44%p 낮았습니다.

즉, 더 많은 이용자를 유입시킨 것이 더 많은 이용자를 장기적으로 유지했다는 뜻은 아니었습니다.

[상세 분석](docs/findings/analysis_02_retention.md)

### 3. 핵심 PvE 진입 전 이탈

Astra 이벤트 기간의 일반 난이도 보스 참여율은 평상시 기준의 82.2%에 그쳤습니다. 하지만 실제 전투에 진입한 이용자의 클리어율과 평균 시도 횟수는 정상 범위였습니다.

따라서 관찰된 문제를 보스 난이도로 단정하지 않고, 이벤트 유입에서 핵심 콘텐츠 진입으로 이어지는 전투 이전 구간의 이탈 문제로 정의했습니다.

[상세 분석](docs/findings/analysis_03_pve.md)

### 4. 신규 구독 상품과 기존 상품 약화

신규 PvE 구독 상품 출시 후 일평균 매출은 72.2%, 결제 이용자는 44.2% 증가했습니다. 그러나 신규 구독 상품이 설명한 매출 증가분은 25.5%에 불과했고, 이후 14일간 기존 반복 판매 상품 3종의 서비스 결제자·일 기준 매출은 9.9% 감소했습니다.

개별 구매자의 상품 전환을 확인할 수 없는 집계 데이터이므로 카니발라이제이션으로 단정하지 않고, 상품 포트폴리오 재배분 경고로 판단했습니다.

[상세 분석](docs/findings/analysis_04_monetization.md)

### 5. 장애 이후 불완전한 회복

전면 장애로 모든 관찰 가능한 활동과 결제가 0까지 하락했습니다. 보상 이후 복귀 이용자는 기준선의 293.9%까지 증가했지만, 매출은 56.2%만 회복했습니다.

일간 운영 지표는 이후 회복 기준을 충족했지만 D30 리텐션은 장애 전 기준보다 1.23%p 낮았습니다. 이에 따라 기술적 복구, 이용자 복귀, 매출 회복과 장기 리텐션 회복을 서로 다른 단계로 구분했습니다.

[상세 분석](docs/findings/analysis_05_incident.md)

### 6. 공통 위험과 지역별 우선순위

세 지역에 공통된 문제 외에도 서로 다른 지역별 신호가 확인됐습니다.

- **KR:** 장애 이후 신규 유입 약화 원인 진단
- **JP:** 신규 구독 출시 직후 기존 상품군 약화 점검
- **Global West:** 추가 유입 확대 전 리텐션 품질 검증

따라서 하나의 글로벌 평균으로 모든 지역의 문제를 통합하지 않고, 공통 가드레일과 지역별 실행 우선순위를 분리했습니다.

[상세 분석](docs/findings/analysis_06_regional_strategy.md)

## 64개 자동화 테스트

분석에 앞서 생성 데이터와 분석 결과를 그대로 신뢰하지 않고 다음 범위를 자동으로 검증했습니다.

- 테이블별 Grain 완전성 및 중복 여부
- KPI의 음수·결측·비정상 값
- 결제 이용자가 DAU를 초과하지 않는 규칙(`PU ≤ DAU`)
- 리텐션 및 보스 퍼널 계층
- 상품 정가와 집계 매출의 정합성
- 일별 총매출과 상품별 매출의 reconciliation
- 출시 전 상품 매출 발생 여부
- 비교 기준선과 분석 기간의 중첩
- 미완성 관찰 기간의 분석 제외
- 신규 상품 출시 구간의 매출 분해
- 수익화 경고 조건과 회복 임계값
- 장애 단계별 기간 경계
- 지역별 가드레일과 최종 분석 판단

테스트 구성은 다음과 같습니다.

| 리텐션 | 8 |

## 핵심 결론

이 서비스는 이벤트를 통해 관심·트래픽·매출을 만들 수 있었지만 다음 세 전환 구간에서 반복적으로 가치를 잃었습니다.

1. 캠페인 인지와 유입 → 핵심 콘텐츠 진입
2. 신규 상품 성장 → 기존 상품 포트폴리오 안정성
3. 기술적 복구와 이용자 복귀 → 매출·장기 리텐션 회복

우선 공통 이용자 단위 진단과 데이터 가드레일을 구축한 뒤, 지역별 증거에 따라 KR의 유입·온보딩, JP의 반복 상품 포지셔닝, Global West의 리텐션 품질을 순서대로 검증하는 방안을 제안했습니다.

## 데이터 출처와 한계

이 프로젝트의 비즈니스 질문, KPI 관계와 운영 시나리오는 작성자의 글로벌 게임 라이브서비스 운영 경험을 바탕으로 설계했습니다. 그러나 모든 행, 수치, 이벤트명, 상품과 일정은 프로젝트를 위해 독립적으로 생성했습니다.

- 실제 이용자·회사 데이터는 사용하지 않았습니다.
- 실제 회사의 스키마·식별자·장애 사례는 포함하지 않았습니다.
- 집계 합성 데이터이므로 인과관계를 입증하지 않습니다.
- 개별 이용자의 결제·가챠·캐릭터 보유·감성 데이터는 포함하지 않습니다.
- 신뢰는 직접 측정하지 않고 리텐션과 결제 행동을 대리 지표로 사용합니다.
